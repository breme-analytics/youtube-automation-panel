# Control panel

A static web page for steering a private YouTube bot. It has no server and holds no data or keys: it runs in
your browser and talks only to GitHub's API, using a GitHub token you paste in. The token stays in your browser.

The source and documentation live in the bot's private repository (`panel/` and `docs/GUIDE.md`). Changes are
published from there with `panel/publish.sh`; don't edit these files here.
